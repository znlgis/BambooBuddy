# 三款隐藏小游戏方案 · 竹林小门

> 状态：**已确认，实施中**（2026-10-20 与用户确认，按本文档执行）｜日期：2026-10-20
> 关联：README、docs/技术方案.md、packages/progress、apps/site

**一句话**：孩子完成当天四件小事后，小屋墙上会悄悄出现一扇小竹门；推开门是一个「竹林游戏厅」，三款经典微信小游戏（消灭星星 / 弹一弹 / 俄罗斯方块）按 4–8 岁重做，每天每款玩一次。**不给竹笋、不给成长值**——好玩本身就是奖励。

---

## 1. 孩子看到的时间线

```text
早上：小屋 / 任务页照旧，界面上没有任何彩蛋痕迹
     │
完成第 4 件【不同的】今日小事
     │
     ├─ 奖励照旧（竹笋 / 星星 / 碎片 / 贴纸）
     └─ 结算浮层多出一行：「咦，竹林后面有一扇小门…」
          │  [推开门]        [等会儿]
          ▼
小屋墙上多了一扇亮着的小竹门（当天有效）
     │ 推门
     ▼
竹林游戏厅：三张卡片（今天还能玩 / 今天玩过啦·明天再来 / 最好成绩）
     │
     ▼
全屏小游戏：一局 60–120 秒 → 撒花 → 回游戏厅，这张卡变成「今天玩过啦」
     │
第二天 00:00：小门消失，重新攒四件小事
```

## 2. 解锁规则（精确定义）

- **今日任务**：任务页「今日推荐」的 4 件。数量常量收在 packages/progress/src/daily.ts 的 4（推荐函数的默认值），页面与解锁判定共用同一个常量，以后改数量只改一处。
- **完成**：日记录 days[今天].completed 里出现该任务 id（已去重，重复玩同一件不计数）。
- **判定**：今天完成的不同任务数 ≥ 4。由日记录直接派生，不额外存「已解锁」布尔值。
  - 为什么按数量、不按「今日推荐的这 4 件」：推荐集是 日期 + 时段 做种子的，中午/晚上会换一批（现在就是这样）。按集合判定会出现「上午解锁、中午又锁上」的怪事；按数量判定天然稳定，且孩子做到 4 件就是做到了 4 件。
  - 备选（更严格）：把当天第一次打开时的推荐 4 件冻结进存档，必须完成这 4 件。代价是改核心任务页的取数逻辑，本轮不建议。
- **当天持续有效**：日记录只增不减，解锁后当天一直有效。
- **跨天重置**：沿用本地日 key（不是 UTC），午夜自动重新计数。
- **隐藏**：未解锁时界面上没有任何入口、没有进度提示。直接访问 #/arcade 送回小屋，不给孩子一个「锁着的页面」。
- **边界情况**：

| 情况 | 结果 |
|---|---|
| 重复玩同一件任务 4 次 | 只算 1 件，不解锁 |
| 第 4 件在 23:59 完成 | 当天解锁；`00:00` 后重新攒 |
| 应用跨夜挂在后台 | 回前台 refresh() 后按新的一天算 |
| 老存档（v1）已有 4 件完成 | 今天就有门，不补弹浮层（浮层只在「这一刻跨过 4」时弹） |
| 清档 | 回到 0 件，门消失 |
| 只完成 3 件 | 没有任何提示（完全隐藏） |

## 3. 三款游戏（借鉴微信小游戏，按儿童重做）

共同原则：**无倒计时、无扣命、无失败、无评分羞辱**；一局短、随时能退出；点按区域 ≥ 96 逻辑像素；不靠颜色单独传达信息（色盲友好）；尊重 prefers-reduced-motion。

### 3.1 消灭星星（PopStar）

| 项 | 方案 |
|---|---|
| 保留的核心乐趣 | 一按爆掉一大片、下落补星、连消越来越爽 |
| 棋盘 | 8 列 × 10 行（原作常见 10×10；格子约 88 逻辑像素，小手好点） |
| 方块 | 4 种「星星家族」：颜色 **+ 各自的形状花纹**（圆点/圆环/爱心/小花），色盲也能分 |
| 消除 | 4 邻接连通同组 ≥2，点击整组消除；组越大音调越高（复用 AudioBus.tone） |
| 补星 | 上方下落压缩，顶部按种子补新星（确定性，可单测） |
| 无解处理 | 没有 ≥2 的组时**不失败**：剩下的星星「自己飞回天上」计入收集，棋盘刷新 —— 保留原作清盘节奏，去掉失败 |
| 一局 | 3 轮，目标收集 24 / 32 / 40 颗，进度条是一只小竹筐 |
| 提示 | 8 秒不动，自动轻闪当前最大的一组（不强制） |
| 时长 | 约 60–90 秒 |
| 计分 | 一局收集的星星总数（最高 96），存最高分 |
| 自动通关 | 每 120ms 选中当前最大组，走与真实点击同一个消除函数 |

### 3.2 弹一弹（Bounce / 弹球打方块）

| 项 | 方案 |
|---|---|
| 保留的核心乐趣 | 瞄准 → 弹射 → 到处反弹 → 一串方块碎掉 |
| 操作 | 按住屏幕任意位置拖动瞄准（不必按在发射器上），松手发射；虚线 + 最近两次反弹点预测 |
| 方块 | 1 击碎（没有数字血量，不做算术）；碎块变成小星星飞进竹筐 |
| 球 | 同时最多 3 颗；一颗球反弹 8 次后回到发射器；装弹 0.9 秒（节奏感，不靠惩罚） |
| 压力 | 每发射 6 次，方块整体下沉一格（保留原作的越拖越紧）；贴到底部时**不失败**，方块「开出小花」无害地飞走并计入收集，本轮直接完成 |
| 一局 | 3 轮：6 / 9 / 12 个方块；中间混 2 个「弹弹方块」（弹性更高）做变化 |
| 时长 | 约 90 秒 |
| 计分 | 收集到的星星数（每块 3 颗） |
| 自动通关 | 瞄准最近的方块，走同一条「发射 → 定步长推进」逻辑 |

### 3.3 俄罗斯方块（Tetris）

| 项 | 方案 |
|---|---|
| 保留的核心乐趣 | 拼、消行、越堆越高的紧张感 |
| 棋盘 | 8 列 × 14 行（原作 10×20；格子约 90 逻辑像素） |
| 方块 | 7 种，7-bag 种子随机；右侧 2 个「下一个」预览；落点影子 |
| 操作 | 4 个大按钮（← → 旋转 ↓）+ 一个大按钮「掉下去」；也支持滑动/点按 |
| 不做 | hold（暂存）—— 对 4–8 岁是多余的认知负担 |
| 速度 | 起始 1.1 秒/格，消行后缓慢加快，最快 0.55 秒/格（绝不出现「眨眼就没了」） |
| 一局 | 累计消 3 行即完成，约 60–120 秒；一次消 2 行有语音夸奖 |
| 堆到顶 | **不失败**：竹竹跑出来说「我们把它们变成彩虹吧」，最下面 4 行变彩虹消掉（并计入 1 行进度）继续玩 |
| 计分 | 消除行数 × 10 |
| 自动通关 | 纯逻辑 AI（枚举旋转 × 列，按高度/空洞/消行评分），在场景内以 80ms/块 的节奏落子 |

## 4. 技术落点

### 4.1 为什么不复用现有的玩法模板

现有 8 个模板是「内容 JSON 驱动 + 判分 + 星星 + 发 task:complete」的日常玩法；三款彩蛋是实时街机（自己的状态机、帧循环、反弹物理、AI），硬套会把模板层撑坏，也会把「任务」概念漏进彩蛋系统。所以：**新契约 + 新包 + 新宿主**，只复用视觉与音频工具。

### 4.2 新契约（不 import Phaser）

新增 packages/game-kit/src/arcade.ts：

```ts
export const ARCADE_GAME_IDS = ['popstar', 'bounce', 'tetris'] as const;
export type ArcadeGameId = (typeof ARCADE_GAME_IDS)[number];

export interface ArcadeManifest {
  id: ArcadeGameId;
  title: string;
  version: string;
  designSize: { width: number; height: number };
  ageRange: [number, number];
}

export interface ArcadeEventMap {
  'arcade:start': { gameId: ArcadeGameId; at: number };
  'arcade:round': { gameId: ArcadeGameId; round: number; totalRounds: number };
  'arcade:complete': { gameId: ArcadeGameId; score: number; durationMs: number };
  'arcade:exit': { reason: 'complete' | 'quit' };
}

export interface ArcadeContext {
  container: HTMLElement;
  manifest: ArcadeManifest;
  services: PlatformServices;   // 复用现有平台出口：只用到 audio / now
  locale: Locale;
  reducedMotion: boolean;
  debug?: DebugOptions;        // ?autoplay=1 / ?instant=1 同一个开关
  emit<K extends keyof ArcadeEventMap>(type: K, payload: ArcadeEventMap[K]): void;
  requestExit(reason?: 'quit'): void;
}

export interface ArcadeModule {
  manifest: ArcadeManifest;
  mount(ctx: ArcadeContext): Promise<void>;
  unmount(): Promise<void>;
  pause(): void;
  resume(): void;
}
```

### 4.5 存档（唯一需要动 schema 的地方）

```ts
// packages/game-kit/src/contract.ts
interface ArcadeProgress {
  best: number;                   // 最高成绩
  plays: number;                  // 总共玩过几局
  lastPlayedDay: string | null;   // 最后一次玩的本地日
}

interface SaveData {
  ...
  arcade: Record<ArcadeGameId, ArcadeProgress>;   // 跨天保留
}

interface DayRecord {
  ...
  arcade: ArcadeGameId[];   // 今天玩过哪些（去重；一天一次的限制就读它）
}
```

- SAVE_SCHEMA_VERSION 从 1 升到 2，补一条 MIGRATIONS[1]（只补字段；sanitize 逐字段兜底，老档的竹笋/星星/成长值一根都不会少）。
- 一天一次：day.arcade 里有这个 id 就进不去；深链也拦。
- **次数在一局真正结束时才消耗**：中途退出算没玩，孩子误触不会损失当天机会。
- 游玩时长照旧走 addPlaySeconds（家长页的 20 分钟休息提醒继续有效）。
- 游戏代码不碰存档（铁律 2）：游戏只发 arcade:complete，外壳负责写档。

### 4.6 文案、语音、音效

- packages/i18n 新增约 30 个键：游戏厅标题 / 小门发现 / 三款名称与一句话说明 / HUD（第 n 轮、继续、掉下去、今天玩过啦…），中英各一份；少写一个键 typecheck 就报。
- 语音：进入每款游戏、第一轮开始、完成时各一句 TTS（中英由 ctx.locale 决定，复用 AudioBus.speak）。
- 音效：复用现有 SfxKey（tap / pop / sparkle / correct / complete），不新增音频通道，也不加音频文件。

### 4.7 调试与自动化约定（沿用现有铁律 3）

- #/arcade/popstar?autoplay=1&instant=1 自动通关（与十个日常玩法同一条约定、同一个 debugAllowed 栅栏）。
- window.__bamboo.events 新增 arcade:start:<id> / arcade:complete:<id> / arcade:exit:<reason>，e2e 只读事件与存档，不猜 DOM。
- 真实手势用例：消灭星星（点最大组）、弹一弹（拖拽瞄准→发射）、俄罗斯方块（点按钮落子）。

## 8. 风险与取舍

- **代码量**：三款实时玩法的代码量约为十个日常玩法的 60%。逻辑单测 + autoplay 是防回归的主要手段；场景只做画与喂手势。
- **不会玩的孩子**：三款都无失败路径（无解自动收集 / 贴底变花 / 堆顶彩虹），最坏情况是「看着它自己变好」，不会卡死、不会输。
- **成瘾边界**：每天最多 3 局、每局 1–2 分钟，合计 ≤ 5 分钟；20 分钟休息提醒照旧；没有排行榜、没有推送、没有内购。
- **体积**：三个新 chunk 只在点进小游戏时下载；首屏一分不涨。
- **与现有玩法的边界**：彩蛋不写任务存档、不发 task:complete、不给奖励，因此不会污染连续天数 / 贴纸 / 家长页的任务统计。

## 9. 待确认（默认值已给出）

1. **解锁口径**：默认「今天完成 4 件不同任务」；备选「必须完成今日推荐的那 4 件」（需要把每日计划冻结进存档，改动更大）。
2. **奖励**：默认不给竹笋 / 成长值，只留「最好成绩」；备选：给 1–2 根竹笋或一点心情值。
3. **隐藏程度**：默认完全无提示；备选：完成 3 件后小屋地毯下透出一点光（提前暗示）。
4. **记录**：默认家长页加一行「今天玩了 N 局小游戏」、日记加一句；备选：都不做，纯彩蛋。

### 实施中定下的细节

1. **计分口径要让「最好成绩」有意义**：消灭星星=实际收集的星星数；弹一弹=星星 + 同发连击奖励（第 2、3… 块每块 +5）；俄罗斯方块=消行数 × 10 + 落子块数。共同点是只增不减、没有失败扣分。
2. **表扬条单槽**：轮次提示与「这一轮完成啦」会在轮次切换时连续出现，公共底座只保留最新一条，并下移到 HUD 之下的 y=330，不遮住目标药丸。
3. **预览层级**：俄罗斯方块的「下一个」框画在 HUD 层，预览方块必须更高一层，否则会被框底色盖住（已修）。
4. **aria-disabled 不用于「今天玩过」的卡片**：卡片仍然可点（点了给一句「今天玩过啦」），否则 Playwright 与读屏器都会把它当成不可操作元素。
5. **首屏预算**：新增的入口/路由/状态让首屏 gzip 从 58.6 → 59.2 KB（预算 60 KB）；竹林小路再加 0.8 KB 后顶到 60.0，于是把日记页也改成路由懒加载，首屏回到 58.9 KB。三款游戏的 chunk 分别 ≈4.3 / 5.5 / 4.3 KB gzip，Phaser 仍走共享 chunk。

## 11. 追加：竹林小路（隐藏触发，2026-10-20）

在「完成四件小事才能开门、每款每天一次」之外，增加一个隐藏触发：**在小屋里连续点竹竹 7 次（5 秒内）**。

| 项 | 行为 |
|---|---|
| 触发 | 竹竹每被点一下都会轻轻弹一下；第 7 下触发彩蛋 |
| 效果 | 当天小门**直接打开**（不用先攒四件小事），三款游戏**无限畅玩** |
| 存储 | `DayRecord.arcadeSecret: boolean`（schema v3，跨天自动失效） |
| 判定 | `arcadeUnlocked = 完成数 ≥ 4 || arcadeSecret`；`arcadeAvailable = 解锁 && (arcadeSecret || 未玩过)` |
| 奖励 | 依旧不发竹笋/成长值/贴纸，只累计局数与最高分 |
| 反馈 | 全屏浮层「嘘——竹竹带你走小路」+ 解锁音效 + 语音；小门卡片与游戏厅显示「∞ 无限畅玩」 |
| 边界 | 当天重复触发只当摸摸头（不重复弹浮层）；第二天不做四件小事就回到「锁着」的状态 |
| 首屏体积 | 触发逻辑与浮层让首屏多了约 0.8 KB；把日记页也改成路由懒加载后，首屏回到 58.9 KB（预算 60 KB），门禁仍有 1.1 KB 余量 |

为什么放在竹竹身上：它是小屋的视觉中心，连点 7 次是孩子会做的事、大人不会凑巧触发；触发点又和「完成四件小事」完全分开，两个入口互不打扰。

验收补充：`pnpm verify` 167 个单测全绿；`pnpm e2e` 30 条中 28 通过、2 条 preview 用例跳过（含新增的「连点竹竹 7 次 → 两局同一游戏都完成」用例）。
