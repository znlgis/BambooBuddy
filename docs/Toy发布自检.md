# Toy 上线自检：按 B 站审核规则过一遍

> 依据：[《Toy 开发者 FAQ》](https://www.bilibili.com/opus/1241171666570051585)（更新至 2026.10.23）与
> 官方仓库 `bilibili/toy` 的 `content-checklist.md`；发布入口 <https://www.bilibili.com/toy/publish/guide/faq>。
> 日期：2026-11-12。**平台规则会变，上传前以线上 FAQ 为准。**

`pnpm toy:check`（已接入 `pnpm verify`）会在构建后机检其中可自动化的几条：入口 `index.html` ≤ 1MB、
整包 ≤ 50MB、资源引用全是相对路径、源码里没有自由输入/UGC 能力、产物里没有站外链接。
剩下的人工项见下面各节。

---

## 1. 已经满足的红线

| 规则（FAQ 原文口径） | 本项目的状态 |
|---|---|
| 不得放置广告 | 零广告位、零推广入口；`HomeExtras` 的「请小鸟吃竹笋」是纯动画奖励，不给数值增益也不导流 |
| 不得跳转站外链接 | 全站无外链：文案、按钮、分享都是站内路由（`navigate()` 只改 hash） |
| 不得出现第三方平台登录/跳转 | 没有账号体系，不读取也不展示任何第三方身份；Toy 自带的 B 站登录态完全没用到 |
| 不得允许用户自建昵称/头像 | 没有昵称、头像、任何可编辑身份；界面里只有固定的「竹竹」 |
| 不得提供 UGC（聊天、画板、上传） | 无聊天、无画板、无文件上传、无摄像头采集；成人门原本的 `<input>` 已换成屏幕数字键盘 |
| 素材版权 | 全部界面与角色由代码绘制（Phaser/Pillow 几何图形），无位图素材、无音频文件、无字体文件；音效由 WebAudio 振荡器合成，旁白走系统 TTS |
| 不得以锁死基础功能换取附加体验 | 十个日常小游戏全部直接可玩，不需要看广告、不需要关注、不需要连续登录；隐藏街机只是彩蛋，锁住的也不是主线 |
| 不得常驻式引导干扰体验 | 引导只有首次进入的一句邀请，可点「等会儿」；没有横幅、弹窗轰炸、倒计时催促 |
| 不涉政、不涉黄、不侵权 | 题材是幼儿生活自理，无政治、宗教、软色情、暴力元素；不含第三方商标或角色 |
| 名称/封面/标题/图标 | 名称「熊猫宝宝的一天 · Bamboo Buddy」为原创，不含「官方」「B 站」等平台字样；封面与图标见 3.3（上传前需补齐） |

## 2. 已修掉的问题（本次改动）

1. **自由文本输入（UGC 红线）** —— 家长门的成人验证原来是一个 `type="text"` 的输入框，
   键盘上什么都能打。Toy 对自由输入的口径是「需自行接入内容安全审核」，而独立小游戏没法接平台审核，
   所以改成**屏幕数字键盘**（0–9 + 退格，最多三位；实体键盘只认数字、退格与回车）。
   门里现在没有任何自由文本，连输入网址的入口都没有；成人验证强度不变（两道两位数加法）。
   相关文件：`apps/site/src/components/AdultGate.vue`、`e2e/shared.ts`、`e2e/parent.spec.ts`。
   改完的样子：`docs/toy/gate-preview.png`（数字键盘 + 只读输入区）。
2. **隐藏小游戏的商标风险** —— 三款彩蛋游戏原来的中文名直接用了别人的作品名
   （消灭星星 / 弹一弹 / 俄罗斯方块），审核侧可能按侵权驳回。改为原创名：
   **星星抱抱 / 竹球弹弹 / 竹块叠叠**（英文 Star Hugs / Bamboo Ball / Bamboo Blocks）。
   内部 id（`popstar` / `bounce` / `tetris`）与路由保持不动，只改了玩家能看到的名称。

## 3. 上传前必须做的配置（代码之外）

### 3.1 分类不要选「游戏」

FAQ 第 13 条：**类型设为「游戏」后，未成年人将自动无法游玩。**
本作的目标用户是 4–8 岁，选「游戏」等于把目标用户挡在门外。
建议选 **「工具」或「互动玩法」** 分类，并在简介里写清「面向 4–8 岁的日常生活养成互动」。
（若平台规则更新，以发布页的分类说明为准。）

### 3.2 包体与入口

- 只传构建产物 `apps/site/dist` 打包出的 zip，**不要传源码**；产物里已经有 `index.html`。
- 入口 `index.html` 解压后必须 ≤ 1MB（当前构建约 1KB 量级，远低于上限）；整包 ≤ 50MB（当前约 1.3 MB）。
- 分享链接带 `index.html`：`https://www.bilibili.com/toy/<slug>/index.html`。
- `slug` 发布后不可改，想好再填（只允许字母、数字、下划线、连字符）。
- 资源路径已全部相对（`base: './'`），hash 路由，刷新与直达都不会 404。

### 3.3 封面与图标

- 封面：仓库已按 4:3 出图 —— `docs/toy/poster.png`（1200×900，程序化绘制，无版权素材）。
  仓库里的 `docs/screenshots/home.png` 是 780×1688 竖屏截图，**不能直接当封面**。
- 图标：`docs/toy/icon-512.png`（512×512）。图标是独立字段，不是封面的缩略版；上传前按发布页给的上限再压一次。
- 封面/图标本身也要过审，审核期间不显示属正常现象。

### 3.4 简介与说明文案

建议在简介里写明：**不联网、不采集、无广告无内购、存档只在本机**（与家长页口径一致），
并注明适龄 4–8 岁。这类说明能减少「面向低龄却诱导消费/收集信息」的误判。

## 4. 发布后的自查清单

- [ ] 上传包只含 `dist`，根目录有 `index.html`
- [ ] 分类不是「游戏」（避免未成年人被挡）
- [ ] 封面 4:3 横图、图标独立上传、都不是热链
- [ ] 简介写清适龄、零收集、无广告内购
- [ ] 分享链接带 `/index.html`
